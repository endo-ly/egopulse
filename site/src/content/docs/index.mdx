## インストール

Linux / macOS なら、以下のコマンドでインストールできます。OS とアーキテクチャを自動判別し、最新のバイナリを `$HOME/.local/bin` に配置します。

```sh
curl -fsSL https://raw.githubusercontent.com/endo-ly/egopulse/main/scripts/install.sh | bash
```

[ドキュメントを読む →](install/)
